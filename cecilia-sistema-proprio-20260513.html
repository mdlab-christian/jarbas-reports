Limitacoes Conhecidas e Mitigacoes

⚠️ EPROC so ve movimentacoes do nosso polo
Mitigacao: Datajud API complementa — retorna movimentacoes de ambos os polos sem filtro de OAB. Estrategia: Datajud para descoberta completa, EPROC para obter conteudo do documento.
⚠️ Sessao EPROC expira / risco de CAPTCHA
Mitigacao: Ja resolvido na Cecilia v6 — 5 sessoes gerenciadas com TOTP automatico via otplib. Rate limiting preventivo: max 50 processos/ciclo por OAB.
⚠️ Lag de 6-8h vs. webhook Judit (~1h)
Mitigacao: Para o perfil do escritorio (triagem diaria), 3 ciclos/dia e suficiente. Se necessario no futuro: contratar Judit somente para webhook de eventos urgentes (~R$1.000/mes vs R$7.637) — economia de R$6.637/mes mesmo no pior cenario.
⚠️ Playwright e fragil — mudancas de layout EPROC quebram
Mitigacao: Ja convivemos com isso na v6. Monitoramento de erros + alerta Telegram quando sessao falha. Custo de manutencao estimado: 1-2h/mes. Custo de nao ter: R$7.637/mes.

Analise de Decisao — Christian Paz / MDX LegalTech
Decisao
NAO contratar Judit API
Razoes
  • Judit nao entrega conteudo para TJRS — 92% dos processos do escritorio sem attachment (TJRS = 0% em 36 tentativas)
  • Custo 25x o necessario: R$7.637/mes vs ~R$300/mes (sistema proprio + Claude API)
  • Sistema proprio ja esta 60% construido — Workers B/C, pipeline, tabelas, sessoes EPROC
  • EPROC gera 15x mais conteudo real que Judit entregou (2.446 chars vs 164 chars)
Acoes Imediatas — esta semana
1
Suspender os 96 trackings Judit — evitar cobranca do plano. Migrar para cecilia_jobs com fonte='eproc'.
2
Iniciar T01 — Datajud Discovery. API publica gratuita, sem autenticacao, cobre TJRS/TJSC/TJSP. Implementar Worker A v2 com poll 3x/dia.
3
Joao cria PB8 em paralelo — playbook de step_type semantico sem dependencia de attachment. Classificacao de eventos baseada em conteudo textual disponivel.
Nota sobre os 96 processos registrados: Esses registros no Judit sao apenas dados de configuracao — as movimentacoes historicas coletadas em cecilia_movimentacoes_brutas sao preservadas. Apenas a fonte futura muda de 'judit' para 'eproc'.
