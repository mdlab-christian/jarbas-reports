2. Achados P0 da investigação direta #

Investigação direta SQL no Supabase MdFlow (qdivfairxhdihaqqypgb) + leitura de código + 4 agents BG paralelos.

  • P0-01 · cecilia_config NÃO é tabela chave/valor Lovable assumiu cecilia_config WHERE chave='cron_hours'. Realidade: tabela com colunas tipadas dedicadas (cron_ativo bool, cron_hours TEXT[], budget_cap_usd numeric, oabs_ativas TEXT[], schedules_json jsonb, self_healing_enabled, datajud_enabled, alert_cost_threshold_usd). Reescreve hooks/queries inteiros.
  • P0-02 · jarbas_accounts.horarios NÃO EXISTE Lovable propôs override por OAB nessa tabela. Não existe. Tabela correta: cecilia_capture_config (com oab, tribunal, ativo, modo_padrao, horarios JSONB). 3 fontes conflitantes de horários hoje: cecilia_config.cron_hours (global) + cecilia_config.schedules_json (por-OAB com retry_offset_h) + cecilia_capture_config.horarios (por-OAB simples).
  • P0-03 · Schema drift ATIVO em cecilia_health TS declara ultimo_heartbeat_at, ultimo_ciclo_at, proximo_ciclo_at. DB real só tem ultimo_sucesso. CeciliaSubOABs.tsx:84 faz select desses campos inexistentes — erro silenciado em produção.
  • P0-04 · cecilia_ciclos JÁ EXISTE Tabela tem 76 linhas com TODOS os campos para timeline 7d (oab, tribunal, ciclo_horario, iniciado_em, concluido_em, status, processos_verificados, documentos_lidos, erros, metadata). Lovable propôs view materializada nova baseada em jarbas_logs (que está vazia, 0 linhas). RPC rpc_cecilia_timeline_7d agregando cecilia_ciclos direto.
  • P0-05 · cecilia_health tem só B e C, sem A DB hoje: 2 linhas — worker='B' (oab=null, último sucesso hoje 14:47) e worker='C' (oab=null, último sucesso null). Worker B está vivo no DB (Lovable assumiu morto). Investigar backend antes de remover do type.
  • P0-06 · Sistema PARALELO duplicado em /controller/ Existe sistema legado ControllerMonitoramento*.tsx (Monitoramento, OABs, Ciclos, Logs, Fila, Config) duplicando sub-tabs Cecília. Lovable não viu. ControllerMonitoramentoConfig.tsx usa rpc_update_capture_schedule + jarbas_accounts.horarios — fonte diferente de CronEditor.
  • P0-07 · PauseWorldDialog JÁ EXISTE CeciliaSubComandos.tsx:52-137 tem componente completo com input "PAUSE", step 1/2, AlertDialog. Lovable propôs criar do zero — violação P-09 DRY.
  • P0-08 · CeciliaSubComandos.tsx:193 faz INSERT com fase: 'B' Se Worker B for removido do type sem decisão sobre backend, esse insert vira dead-code OU cria job órfão na cecilia_jobs.
