Regra Absoluta

Um cliente = sempre o mesmo advogado em TODOS os seus processos. Jamais dois advogados diferentes para o mesmo cliente. Se a procuracao indicar advogado diferente do registrado no CRM para este cliente — erro critico, mover para Revisao Humana.

O que NAO flaggar

Ausencia de assinatura do advogado na procuracao (nao e necessaria). "R$" duplicado no documento (falha de atendente, nao e erro critico para bloquear distribuicao).

Logica Boa Vista — Regra Mais Importante

Boa Vista e ORGAO ARQUIVISTA + EMPRESA ao mesmo tempo
Essa dualidade e a regra mais critica para entender o sistema — toda a logica de processamento depende dela
Bloco A — Boa Vista como Orgao Arquivista
Todas as restricoes do SCPC sao armazenadas no banco da Boa Vista
O comprovante gerado pela Julia = relatorio completo de TODAS as restricoes do CPF
Esse comprovante e universal para todos os processos (exceto os com restricao especifica de outra empresa)
Bloco B — Boa Vista como Empresa Re
Se o cliente tem PENDENCIA FINANCEIRA com a propria Boa Vista → processo contra Boa Vista
Esse processo usa o valor da restricao especifica da Boa Vista no relatorio
O comprovante BV serve como documento para esse processo tambem
Bloco C — Processavel vs Nao Processavel
PROCESSAVEL
Pendencias Financeiras (credores de empresas)
Restricoes SCPC de empresas especificas
NAO PROCESSAVEL
Protestos em Cartorio (campo "Protestos" do relatorio)
Contumacia
Cheques sem fundo

Bloco D — Multiplas restricoes da mesma empresa
Se empresa X tem 3 restricoes no relatorio BV → pode gerar 3 processos separados (1 por restricao)
Cada processo tem seu proprio valor_causa = 15000 + (valor_restricao / 100) em reais

Comprovante Boa Vista — Anatomia do Documento

Estrutura do PDF gerado pela Julia via API SCPC. Baseado no exemplo real BALTAZAR KLAUS.
Secao do PDF Campos / Conteudo Para o Davi
Header "Relatorio de Auditoria de Restricoes de Credito" + data emissao referencia
Dados da Consulta CPF consultado, data consulta, BASE = "SCPC/Boa Vista" verificar CPF
Identificacao Nome, CPF, data nascimento, Situacao CPF (REGULAR/IRREGULAR), endereco verificar nome/CPF
Quadro de Avisos Cheques BACEN, cheques varejo, pendencias financeiras, titulos protestados, contumacia identificar tipos
Score 0-1000 (Boa Vista SCPC) ignorar
Resumo de Restricoes Total de ocorrencias + valor total contar processaveis
Protestos Tabela: data, cartorio, cidade, valor NAO PROCESSAVEL
Pendencias Financeiras Tabela: vencimento, credor, contrato, valor, tipo PROCESSAVEL — extrair
O que o Davi extrai com GPT-4.1 Mini

Lista de pendencias financeiras processaveis (empresa + valor + contrato) a partir da tabela "Pendencias Financeiras". Tambem verifica se o comprovante esta na pasta correta: empresa da restricao deve ser igual a empresa re do processo onde o comprovante foi colocado.
