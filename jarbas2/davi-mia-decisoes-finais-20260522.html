Arquitetura Final do Davi

MODO 1 — "Validar com Davi" (Tab Ag. Preparacao)
E1
Verificar pasta da restricao
Checar processos.google_drive_folder_id == restricoes.drive_pasta_id. Se divergente: atualizar. Se drive_pasta_id NULL: criar via PASTA-RESTRICAO-v1.
E2
Sincronizar Tier 1 para subpasta
Docs sem restricao_id (procuracao, identidade, residencia, renda_ctps). Copiar referencias para a subpasta no Drive.
E3
Verificar / Gerar Peticao Inicial
sucesso/customizada → OK. NULL/pendente → dispara webhook (fire-and-forget, status "gerando"). falhou → BLOQUEADO.
E4
Verificar / Gerar Comprovante de Restricao
Boa Vista: verificar presenca doc tipo='comprovante_restricao'. Se ausente → BLOQUEADO (manual). Outros: rpc_solicitar_comprovante_restricao.
E5
Verificar valor Boa Vista
restricoes.valor vs processos.valor_causa. MVP: aviso nao bloqueante.
E6
Contar docs por pasta da restricao
Tier 1 + Tier 2 >= 7 → OK. < 7 → BLOQUEADO com contagem atual.
APROVADO

UPDATE etapa = 'aguardando'. INSERT davi_validacoes. Badge verde.

BLOQUEADO

Mantem em preparacao. INSERT com issues[]. Badge vermelho + motivo.

GERANDO

Mantem em preparacao. Badge amarelo "Aguardando PI/Comprovante".

Idempotencia por batch_request_id. Cria distribuicao_lotes com meta.nomes_eproc. Move processos para em_distribuicao.
