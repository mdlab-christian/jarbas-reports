Filtro de distribuicoes — duplicata e historico do dia
limite 30 por OAB · mesmo cliente+empresa · query final
Você é um agente de investigação do projeto MdFlow (SaaS jurídico).
Estou construindo o agente Davi — um sub-agente que monta lotes com no máximo 30
processos por OAB, sem repetir o mesmo cliente contra a mesma empresa no mesmo dia.

INVESTIGUE como o sistema controla distribuições e aplica filtros:

1. Como saber quais processos foram distribuídos hoje:
   SELECT
     p.id, p.cliente_id, p.empresa_id, p.etapa_distribuicao,
     dl.created_at as distribuido_em
   FROM processos p
   JOIN distribuicao_lotes dl ON dl.processo_id = p.id
   WHERE DATE(dl.created_at) = CURRENT_DATE
     AND dl.status IN ('concluido', 'enviado', 'fila', 'processando')
     AND p.deleted_at IS NULL
   LIMIT 20;

2. Existe campo distribuido ou distribuido_em em processos?
   SELECT column_name, data_type FROM information_schema.columns
   WHERE table_name = 'processos' AND (column_name ILIKE '%distribu%' OR column_name ILIKE '%enviado%');

3. Como aplicar o filtro de duplicata (mesmo cliente + mesma empresa no mesmo dia):
   Crie uma query que retorna os pares (cliente_id, empresa_id) que já foram distribuídos hoje.

4. Como o sistema atual seleciona processos para um lote:
   grep -rn "selecionar.*processo\|processo.*selecion\|buildLote\|montar.*lote" /Users/beto/beta-mdflow/src --include="*.tsx" --include="*.ts" | head -20

5. Como os lotes são filtrados por OAB:
   grep -rn "oab\|OAB" /Users/beto/beta-mdflow/supabase/functions/mia-preparar-lote/index.ts | head -20

6. Existe lógica de máximo de processos por lote atualmente?
   grep -rn "max.*lote\|lote.*max\|limit.*processo" /Users/beto/beta-mdflow/supabase/functions/mia-preparar-lote/index.ts

RETORNE relatório markdown com:
- Query exata para verificar distribuições hoje por (cliente_id, empresa_id)
