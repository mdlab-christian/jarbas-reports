Resumo Tecnico

Edge Functions

—davi-validar — 7 checks sequenciais, retorno tipado
—davi-preparar-lote — batch com cache + preview mode
—Cache 24h com bypass via force_revalidar
—Registros em davi_validacoes (76 entradas)
—3 entry points frontend (Tab + Tab + Modal)

Principio de Projeto

Davi opera com determinismo total. Cada erro mapeado tem uma e apenas uma acao possivel. Sem heuristicas, sem sugestoes vagas. A responsabilidade da correcao e sempre clara: Davi (automatico), Davi (semi-auto) ou Usuario (link direto).
