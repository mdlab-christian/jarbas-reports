SUPABASE — SQL Editor M-02 — UUIDs Tania/Raquel no Supabase (R7.3)
pendente

Precisamos dos UUIDs dos usuarios sistema de Tania (atendimento_cp) e Raquel (atendimento_hm) para configurar os agentes. Se nao existirem, precisamos saber para cria-los. Rodar as 2 queries abaixo no projeto qdivfairxhdihaqqypgb.

-- Verificar em mdzap_ai_modules SELECT id, nome, agente_slug, ai_enabled, created_at FROM mdzap_ai_modules WHERE agente_slug IN ('atendimento_cp', 'atendimento_hm'); -- Verificar se ha users sistema SELECT id, email, created_at, raw_user_meta_data FROM auth.users WHERE email ILIKE '%tania%' OR email ILIKE '%raquel%' OR raw_user_meta_data->>'slug' IN ('atendimento_cp', 'atendimento_hm') OR raw_user_meta_data->>'agente_slug' IN ('atendimento_cp', 'atendimento_hm');
O que retornar:
Resultado completo das 2 queries (incluindo "0 rows" se nao encontrar nada).
n8n — Interface web M-03 — Webhook send-otp no n8n (FIX-02)
pendente

Verificar se existe o webhook portal/send-otp ativo no n8n antes de implementar o fluxo OTP do Portal Bia.

  • 1 Acessar n8n: https://primary-production-e209.up.railway.app
  • 2 Buscar workflows com "otp" ou "portal" no nome (campo de busca no painel)
  • 3 Verificar se ha webhook com path /webhook/portal/send-otp ou similar
  • 4 Anotar: nome dos workflows encontrados + se o webhook existe + se esta ativo (verde)
O que retornar:
Nome dos workflows encontrados + se o webhook existe + status (ativo/inativo/nao existe).
