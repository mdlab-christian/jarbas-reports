Anatomia de um agente por script (5 camadas)

Cada agente (Tania, Raquel) e composto por 5 camadas sobrepostas. As camadas 4 e 5 ainda nao existem — sao o principal gap de robustez atual.

C1 SOUL — quem sou 00_cerebro/SOUL.md ✓ presente

Identidade, tom, regras absolutas e templates de mensagem. E o nucleo imutavel do agente.

Deve conter
  • Identidade unica (nome, quem representa)
  • Regras NUNCA violar (minimo 4)
  • Templates por tipo de documento
  • Fluxo de follow-up
  • Situacoes especiais com resposta padrao
Nao deve conter
  • Logica de negocio dinamica
  • Dados do cliente
  • Informacoes que mudam por conversa
C2 STYLE — como falo 00_cerebro/STYLE.md △ limpo hoje

Tom de voz, comprimento de resposta, uso de emoji, vocabulario proibido. Arquivo minimo e focado.

Deve conter
  • 1 paragrafo de tom
  • Tamanho maximo de mensagem
  • Lista de palavras preferidas/proibidas
Nao deve conter
  • Nada que nao seja sobre linguagem
  • Senhas ou dados sensiveis
C3 SKILLS — o que faco 01_skills/recepcao.md △ minima

Logica operacional de cada skill ativa. Define: quando usar, como reagir, qual marcador de sistema usar.

Deve conter
  • Fluxo de decisao SE/ENTAO por situacao
  • Marcadores de sistema ([ESCALAR_HUMANO])
  • Uma skill por modo de operacao
Nao deve conter
  • Misturar cobranca + apresentacao + follow-up
  • Instrucoes genéricas tipo "siga o SOUL"
C4 CONTEXT — quem e o cliente agora 02_context/CONTEXT.md ✗ faltando

Dados especificos do cliente para ESTA conversa. Gerado em runtime pelo n8n — nao commitado no vault.

# Exemplo de CONTEXT.md (injetado via [SISTEMA: ...]) Nome: Joao Silva Pendentes: IRPF, Extrato Bancario Recebidos: Procuracao (recebida 2026-05-20) Ultima: 2026-05-22 Status: aguardando_irpf
Como gerar: n8n injeta via instrucao [SISTEMA: ...] antes de cada chamada ao LLM, consultando documentos_pendentes por cliente_id.

Secao 04

7 Principios Anti-Alucinacao

P1 Mundo Fechado

O agente so responde sobre o que esta explicitamente no SOUL. Qualquer pergunta fora do escopo → script padrao + escalar humano. Nunca tentar responder com "deducao" sobre o processo.

Regra pratica Se nao tem template no SOUL → nao responde.
P2 Injecao de Contexto em Runtime

Nunca confiar na "memoria" do LLM entre mensagens. Injetar via [SISTEMA: ...] no inicio de cada chamada: quais docs estao pendentes, o que ja foi recebido, estado atual.

Regra pratica n8n monta o [SISTEMA: ...] consultando o banco antes de chamar o agente.
P3 Templates Sobre Geracao

Para mensagens criticas (solicitacao de documento, follow-up), usar templates pre-aprovados. LLM so gera texto quando a situacao for imprevista (variacao casual, conversa livre).

Regra pratica Templates no SOUL. Skill instrui quando usar cada um. LLM nao "cria" texto para documentos.
P4 Maquina de Estados Explicita

Definir estados com nome e regras de transicao. O agente nunca volta para estado anterior sem comando humano explicito. Evita loops (pedir mesmo doc duas vezes, voltar para apresentacao).

Regra pratica Estado salvo no banco. Controller injeta estado atual. Skill verifica antes de agir.
P5 Negativo > Positivo

Listas de "NUNCA" sao mais eficazes que instrucoes positivas para prevenir alucinacao. O LLM resiste mais a cruzar uma barreira explicita do que a seguir instrucao positiva que pode ser "interpretada".

Regra pratica Toda regra critica comeca com NUNCA. Ex: "NUNCA mencionar Midas" > "Mencione apenas Christian Paz".
P6 Escotilha de Saida Sempre Disponivel

Toda situacao ambigua tem uma saida definida: awaiting_human: true. O agente nao precisa ser inteligente para lidar com o inesperado — so precisa saber quando parar e chamar humano.

Regra pratica "Se em duvida sobre o que responder → escalar". Melhor silenciar e escalar do que alucinhar.
P7 Validacao de Saida (Output Guard)

Antes de enviar a resposta ao WhatsApp, passar por uma checagem automatica: a resposta contem palavras proibidas? Extrapola o escopo definido? Esta camada ainda nao existe — e uma das prioridades de implementacao.

# Logica do output guard (futura implementacao n8n) SE resposta CONTEM ["Midas", "Christian", "OAB"] em agente da Raquel ENTAO BLOQUEAR + escalar_humano() SE resposta EXTRAPOLA escopo definido no SOUL ENTAO BLOQUEAR + escalar_humano()
