Resumo Executivo

Hermes Agent é o sucessor espiritual do OpenClaw assinado pela Nous Research. Lançado em 25-fev-2026 e já ultrapassando 110 mil stars no GitHub em 10 semanas — o framework de agentes mais rápido a explodir em 2026. Propõe três deltas sobre OpenClaw: (1) memória persistente curada pelo próprio agente com Honcho user modeling, (2) skills self-improving auto-criadas a cada ~15 tool calls e refinadas durante uso, e (3) Pantheon de modelos — divisão de carga entre 5+ modelos por instância (visão, busca, compressão, principal, MCP).

O ponto forte real são profiles multi-instância (~/.hermes/profiles/<nome>/) — cada profile com SOUL.md, memória, sessões, crons e bot próprio. Combinado com migração plug-and-play do OpenClaw (hermes claw migrate: 4 itens, 7 arquivados, 32 pulados, 0 conflitos em segundos, conforme ViktorKav), instalar Hermes ao lado da stack atual é baixíssimo risco operacional.

Recomendação top-level: NÃO migrar tudo. Sim, migrar Jarbas 2.0 (Master no Air) — é o caso de uso paradigmático onde Hermes brilha. Sim, criar 1 profile Hermes orquestrador transversal MdFlow para operação via celular (vibing). Manter intactos pipelines especializados Olivia (pipeline-v4), Cecilia (S0-S9) e Julia (julia-server :8787) — esses agregam pouco e arriscam drift por self-improving sobre tarefas validadas com João/Leonardo.

Regra do Jack Roberts (vídeo 2): "Se você precisa estar lá pra acontecer → Claude Code. Se precisa acontecer sem você → Hermes Agent." Olivia, Cecilia e Julia já acontecem sem ti hoje. Jarbas 2.0 e um orquestrador MdFlow precisam de ti pensando — exatamente onde Hermes brilha.

Riscos e contra-pontos

  • Migração ≠ funcionar igual: os pipelines custom da OlivIA (pipeline-v4) e Cecilia (S0-S9) não são skills — são scripts Node dedicados em ~/Documents/olivia-vault/ e workers A/B/C. Hermes migra config (persona/memórias/allowlist/keys/plataformas), NÃO reescreve o pipeline.
  • Julia NÃO é OpenClaw: é serviço Express :8787 + Cloudflare Tunnel julia.midas.com.br. Migração só duplicaria infraestrutura sem ganho.
  • Self-improving = risco de drift: Cecilia auto-criando skill que muda taxonomia A-G validada com João (audio-23, audio-32) → trabalho de calibração perdido. Self-improving sobre pipeline já calibrado é regressão potencial.
  • Maturidade v0.9: lançado Fev/2026, a própria comunidade Nous recomenda "manual review skills no primeiro mês". Não dá pra colocar em produção crítica sem shadow.
  • Honcho memory é semi-proprietário: não tão portátil quanto agentskills.io. Lock-in moderado se você depender pesado dele.
  • Skill quality varia em tarefas complexas: 50+ tool calls em fluxo único — relatos da comunidade indicam over-generalize, skill captura abstração errada.
  • Custo IA mascarado: Pantheon promete -40-60%, mas auxiliares (curator, compressão, MCP coordinator) adicionam chamadas que o relatório consolidado pode esconder.
