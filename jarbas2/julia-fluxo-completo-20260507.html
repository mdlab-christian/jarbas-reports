Erros, condições especiais e comportamentos de fallback

ERRO — APIFULL
APIFULL 400/429 — API bureau falha
Retry automatico com backoff: 3s → 6s. Apos 2 falhas: leads.julia_auditoria_status = 'erro_apifull'. Status 'erro_*' PERMITE re-run pelo lock do STEP 1. Julia ja respondeu ao lead e nao sabe do erro.
ERRO — CHROME HEADLESS
PDF nao gerado — Chrome headless falha
leads.julia_auditoria_status = 'erro_pdf_gen'. INSERT em julia_skills_audit_log. O lead nao recebe o PDF. Status 'erro_*' permite re-run.
ERRO — META API
Meta API falha ao enviar PDF/texto
Log 'meta_send_failed'. Response HTTP 500 interno. leads.julia_auditoria_status = 'erro_meta_send'. O lead nao recebe o resultado da auditoria.
BLOQUEIO — FORBIDDEN FILTER
Resposta LLM contem palavra proibida
Response bloqueada antes de chegar ao lead. Log 'forbidden_hit'. Julia NAO envia nada. Request termina com 200 (noop). Palavras: tribunal|juiz|advogado|garanto|100%|Perinotti|Paz etc.
SKIP — AWAITING HUMAN
Lead envia msg sem codigo com awaiting_human=true
Skip silencioso. Julia NAO responde. Log 'inbound_skip_awaiting_human'. O especialista humano deve assumir o atendimento. awaiting_human so e resetado se chegar novo codigoMatch.
SKIP — PIPELINE DUPLICADO
Pipeline ja esta rodando (status='rodando')
CAS lock do STEP 1 retorna null (nenhuma linha atualizada). Pipeline skip silencioso. Evita race condition se a mesma mensagem chegar duas vezes.
SKIP — PIPELINE CONCLUIDO
julia_auditoria_status = 'concluida'
CAS lock bloqueia. Pipeline nao roda novamente para este lead. Para re-auditar seria necessario resetar manualmente o status no banco.
CONDICAO — AUDIO SEM URL
Audio chegou mas mediaUrl e null
mediaContextNote indica o problema. LLM recebe nota: "audio sem URL disponivel". Julia pede para o lead digitar em texto.
CONDICAO — IMAGE ANALYSIS FALHA
Vision API Anthropic retorna erro
Fallback graceful: nota contextual e passada ao LLM. Julia responde pedindo para o lead descrever em texto o que enviou.
CONDICAO — JANELA 24H META
julia_ultima_interacao > 24h atras
Followup bloqueado pelo filtro de horario do cron. Nenhuma mensagem outbound enviada. Para entrar em contato apos 24h seria necessario HSM (template) aprovado pela Meta.
DEBUG — SHADOW MODE
Shadow mode ativo (testes)
decidirOutbound() retorna decisao com flag shadow=true. Pipeline loga a decisao sem enviar nada ao lead. Usado para validar comportamento sem impacto real.
GATE — 1A MSG SEM CODIGO
isFirstMsg=true, codigoMatch=null
Gate bloqueia. leads.awaiting_human=true + observacoes='Lead chegou sem codigo'. Retorna noop imediatamente. Julia nunca responde. Requer revisao manual da origem do lead.
