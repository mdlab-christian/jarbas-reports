1. Contexto do Projeto

O que e a Julia?

Agente de IA WhatsApp que atende leads do Midas Atendimento (numero 5551816855848). Opera 24h via Node.js (julia-server) + Claude Anthropic + Supabase + Meta Cloud API.

Quando um lead envia seu codigo de atendimento pelo WhatsApp, a Julia assume: coleta documentos, dispara auditoria, valida comprovante e faz transicao para o atendente humano (Vinicius) na hora certa.

Por que a v3 foi necessaria?

Christian analisou 5.751 mensagens reais de 353 leads e encontrou 7 bugs sistemicos que travavam leads em loop ou silenciavam a Julia na hora errada.
BUG-01
Race condition PDF
Julia dizia "consultando" APOS o PDF chegar — afetou 10/11 leads de sucesso
BUG-02
documentos: {}
Dados de documentos nunca processados — campo vazio em 100% dos leads
BUG-03
memoria_julia: null
Julia perdia historico entre mensagens — afetou 10/11 leads de sucesso
BUG-04
erro_wh_aud_01
Webhook auditoria falhava silenciosamente — Thiago ficou 71 msgs em loop
BUG-05
CPF limpo sem fluxo
Luis Elias ficou 71 msgs em loop "especialista te chama" — sem saida
BUG-06
ZapSign sem polling
5 leads assinaram e o sistema nao sabia — procuracoes nao detectadas
BUG-07
Saudacoes duplicadas
Conflito Julia + n8n: lead recebia saudacao duas vezes no primeiro contato
Comparativo de Fluxo — v2 vs v3
v2 (legado)
Lead [codigo] Julia sauda Sistema envia PDF Lead manda docs Vinicius fecha tudo
v3 (atual)
Lead [codigo] Julia pede ID (RG/CNH) Julia valida docs + Auditoria Julia pede comprovante Julia valida comprovante Transicao para Vinicius (CTPS + ZapSign)
