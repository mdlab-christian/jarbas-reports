Prompts — aplicar na ordem P1 → P2 → P3

P1
Fallback URL julia-server
Critico 
No arquivo src/lib/bia-api.ts, substitui a linha que define JULIA_URL (linha 5) por exatamente:

const JULIA_URL = (import.meta.env.VITE_JULIA_SERVER_URL as string | undefined) ?? "https://julia.jarbas-mdlab.com";

No arquivo src/lib/wizard-events.ts, encontra a linha que define JULIA_URL perto do final do arquivo e substitui pela mesma linha acima.

Nao muda mais nada nesses arquivos.
⚠️ Por que importa: Sem isso, a Bia fica offline sempre que VITE_JULIA_SERVER_URL nao esta no env do Lovable.
P2
Redirect pos-login
Importante 
No arquivo src/routes/login.tsx, verifica se existe um beforeLoad que redireciona para /portal quando o usuario ja esta autenticado ou quando search.done esta definido. Se nao existir, adiciona:

beforeLoad: ({ search }) => {
  if (typeof window !== "undefined" && (search.done || isAuthenticated())) {
    throw redirect({ to: "/portal" });
  }
},

Onde isAuthenticated e importado de @/lib/auth-portal. O redirect e importado de @tanstack/react-router.

Nao muda mais nada.
💡 Por que importa: Sem isso, apos criar as credenciais o usuario fica preso na tela de login.
P3
JWT storage no OTP
Importante 
No arquivo src/hooks/useLoginWizard.ts, dentro da funcao submitOTP, verifica se apos a chamada bem-sucedida ao Supabase RPC fn_cliente_otp_validar existe uma chamada setJWT(result.jwt).

Se nao existir, adiciona logo apos receber o resultado e antes de qualquer update de estado:

if (result.jwt) setJWT(result.jwt);

Onde setJWT e importado de @/lib/auth-portal.

Nao muda mais nada.
💡 Por que importa: Sem o JWT salvo no localStorage, todas as chamadas autenticadas a Bia e ao portal falham.
