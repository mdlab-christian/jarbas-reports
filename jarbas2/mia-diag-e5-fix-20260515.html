Fix Aplicado — v1.2 (Re-navegação Pós-cadastro PJ)

Estratégia: Re-navegar + Re-buscar + Incluir
Ao detectar redirect para painel_adv_listar após salvar o formulário PJ, o worker salva a URL anterior (processo_cadastrar_3_reu com hash da sessão), re-navega, re-busca pelo CNPJ (empresa agora cadastrada) e clica #btnIncluir para inclusão real no processo.
1
Detectar redirect pós-save
Após submeter o formulário PJ, verificar se page.url().includes('painel_adv_listar'). Se verdadeiro, acionar fluxo de re-navegação em vez de declarar reuOk imediatamente.
2
Re-navegar para urlApos (URL salva após click #btnNovo)
Usar a URL salva no evento reu_btn_novo (que contém processo_cadastrar_3_reu com o hash da sessão ativa). Navegar de volta via page.goto(urlApos).
3
Re-buscar pelo CNPJ
Empresa agora está cadastrada no EPROC. Repetir a consulta pelo CNPJ 11.725.176/0001-27 — desta vez btnIncluirExiste deve retornar true.
4
Clicar #btnIncluir → reuOk = true (real)
Com o botão de inclusão disponível, clicar e aguardar confirmação. Somente neste ponto definir reuOk = true. Verificar URL resultante para confirmar retorno ao fluxo de cadastro.
5
Fallback: hash expirado
Se re-navegação falhar (hash de sessão expirado ou URL inválida), logar evento reu_renavegacao_hash_expirado com aviso. Não prosseguir para E6 — abortar o lote e registrar falha tratada.
6
Clicar #btnProxima → E6 na página correta
Após reuOk real, avançar para E6 (Características) na página correta do EPROC. Checkboxes de características e upload de documentos funcionarão com o contexto de processo válido.
