FASE F0 distribuir-tjrs.mjs — Validação e Pré-checks adapters/distribuir-tjrs.mjs
  • 🚫
    Anti-repeat: detecta processo já distribuído
    SELECT etapa_distribuicao FROM processos WHERE id = X
    Se etapa_distribuicao = 'distribuido' aborta imediatamente. Não reprocessa.
  • 📄
    Valida existência da Petição Inicial
    SELECT * FROM processos_documentos WHERE processo_id = X AND tipo_documento = 'peticao_inicial' AND deleted_at IS NULL
    Se não encontrar aborta com evento peticao_inicial_ausente
  • 📎
    Carrega comprovantes de restrição
    SELECT * FROM processos_documentos WHERE processo_id = X AND (tipo_documento = 'comprovante_restricao' OR tipo_documento IS NULL)
    Filtra URLs que apontam para bucket comprovantes.
  • 📁
    Carrega docs do cliente (leadDocs) — Fluxo complexo
    1. SELECT lead_id FROM clientes WHERE id = cliente_id
    2. SELECT * FROM processos_documentos WHERE lead_id = X AND deleted_at IS NULL — metadados do DB
    3. Storage leads-docs/{org_id}/leads/{lead_id}/ lista arquivos root
    4. Storage leads-docs/{org_id}/leads/{lead_id}/restricoes/{restricao_id}/ lista arquivos da restrição
    Mapeamento DB→Storage: keywordsMeta(nome_db) → keywords → mapearMelhor(arquivos_storage, keywords) → empate desfeito por timestamp mais recente
    Ordem final: leadDocs.all = [...restricao, ...root].sort(prefixo_numerico). Prefixo extraído do nome no DB. Ex: "3 - CNH" → 3, "2.2 - Procuração" → 2.2
  • 🏢
    Carrega dados da empresa ré
    restricoes → empresas → cnpj, razao_social, enderecos_empresa
    Usada para preencher o réu no EPROC (fase E5).
  • 📍
    Determina cidade da petição
    pdftotext na petição → regex "Comarca de CIDADE" → Fallback: processos.foro_regional
  • ✏️
    Marca processo como em andamento
    UPDATE processos SET etapa_distribuicao = 'em_distribuicao'

Bugs Conhecidos

BUG-01 Swap auditoria ↔ procuração CRITICO
Causa keywordsMeta usa keyword 'boavista' que também está no nome do arquivo de procuração (ex: "2.2_-_procuracao_boa_vista.pdf"). Quando empata com a auditoria, o desempate por timestamp mais recente dá a vitória para a procuração.
Sintoma Arquivo de auditoria sobe como "Procuração" (code 2). Procuração sobe como "Anexo" (262). Documentos invertidos no processo EPROC.
Fix Remover 'boavista' das keywords de comprovante/auditoria. Usar apenas 'auditoria' e 'negativa' como keywords discriminadoras.
BUG-02 CTPS duplicado (cross-folder) CRITICO
Causa Mesmo arquivo de CTPS salvo em duas pastas do Storage (root e restricoes/). A deduplicação atual corre por pasta separada. Ambos sobrevivem e são enviados ao EPROC.
Sintoma Alerta EPROC "2 ou mais arquivos iguais" → hdnNumDocumentos = 0 → upload não confirmado pelo EPROC → distribuição falha silenciosamente.
Fix Implementar cross-folder dedup no final de carregarDocsLead(), comparando pelo base normalizado de nome de arquivo entre as duas pastas.
BUG-03 Double .pdf em nomeEproc MODERADO
Causa processos_documentos.nome já inclui a extensão .pdf no valor persistido. A função nomeParaEproc(nome) adiciona outro .pdf sem checar.
Sintoma Nome do arquivo no EPROC fica "2.2 - Procuração Boa Vista.pdf.pdf" — extensão duplicada visível no processo judicial.
Fix nomeParaEproc deve fazer strip da extensão .pdf final antes de adicionar a extensão novamente.
