1. Problema → Solução

Problema: Heloísa (advogada Midas) faz pico 10 réplicas/dia. Cada análise IA leva ~110s mediana (medido em produção: 48-156s). Hoje sequencial = abre 1, espera, abre outra, espera = ~30-50min/dia ociosa. Pico simultâneo histórico observado: 5 paralelas.

Solução: Botão [Flow N·M✓] no header da /olivia abre drawer flutuante always-on-side com fila de processos para análise IA em background. Cada processo é adicionado via modal com Step 1 idêntico. Quando análise pronta: 1 clique abre VibeLaw direto no Step 2 (sem refazer análise). Heloísa enfileira 5-10 processos pela manhã, continua trabalhando em outras peças, volta e revisa os prontos.

⚡ Ganho esperado

~15h/mês por advogado (Heloísa: 45min/dia × 22 dias). Em escala (Christian + Heloísa): ~30h/mês economizadas.

Operações Supabase Flow

INSERT (FlowAddModal submit)

await supabase.from('olivia_historico').insert({ organizacao_id: orgId, // obrigatório (RLS) advogado_id: advogadoId, // FK advogados processo_id: processo.id, // FK processos tipo_peticao_id: tipoId, // FK olivia_tipos_peticao modelo_id: modeloId, // NULL = auto-detect qualidade_ia: qualidade, // 'padrao' | 'avancado' status: 'PENDENTE', meta: { origem: 'flow', flow_priority: 0 } }); // Trigger trg_olivia_flow_dispatch AUTOMATICAMENTE invoca EF dispatcher

SELECT (useFlowList query)

await supabase.from('olivia_historico').select('...') .eq('organizacao_id', orgId) // RLS .filter('meta->>origem', 'eq', 'flow') // só Flow .is('peticao_html', null) // não chegou Step 4 .is('arquivado_at', null) // não arquivado .order('meta->>flow_priority', { ascending: true }) .order('created_at', { ascending: true });

UPDATE remover (removeItem)

await supabase.from('olivia_historico') .update({ arquivado_at: new Date().toISOString() }) .eq('id', historico_id);

RPC reorder (drag)

await supabase.rpc('fn_olivia_flow_reorder', { p_historico_id: historico_id, p_priority: newPriority }); // Retorna { success: true, priority: N } ou { success: false, error: '...' }

Realtime (1 channel global)

supabase.channel(`olivia-flow-list-${orgId}`) .on('postgres_changes', { event: '*', schema: 'public', table: 'olivia_historico', filter: `organizacao_id=eq.${orgId}` }, () => queryClient.invalidateQueries(...)) .subscribe(); // IMPORTANTE: 1 channel global, NÃO 1 por card
