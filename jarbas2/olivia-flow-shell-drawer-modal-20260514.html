1. A virada — por que isso é melhor

Plano Air (ontem) tratava Flow como página destino: o usuário vai, configura, volta. Esse modelo quebra o workflow real da Heloísa, que revisa peças e adiciona novas análises ao mesmo tempo.

A virada do CTO transforma Flow em componente flutuante always-on-side: drawer lateral que vive em cima do gerador. Heloísa pode estar editando uma réplica no Step 3 e, sem sair, abrir o Flow para enfileirar 4 processos novos para análise.

9. Detalhes técnicos

Fila local + filtro Supabase

// Drawer carrega via Supabase, filtrando por origem='flow' (sem migration) const { data } = useQuery({ queryKey: ['olivia-flow-queue', orgId, userId], queryFn: () => supabase .from('olivia_historico') .select('id, status, etapa_atual, progresso_pct, analise_estruturada, topicos_gerados, error_message, created_at, processo_id, advogado_id') .eq('organizacao_id', orgId) .eq('advogado_id', userId) .eq('meta->>origem', 'flow') // filtro chave .is('peticao_html', null) // "ainda não chegou ao Step 4" .order('created_at', { ascending: false }), refetchInterval: (q) => q.state.data?.some(i => i.status === 'PROCESSANDO') ? 3000 : false, });

Adicionar processo (modal → fila)

INSERT olivia_historico (status=PENDENTE, meta.origem='flow') const { data: row } = await supabase.from('olivia_historico').insert({ organizacao_id: orgId, advogado_id: userId, processo_id: payload.processo_id, tipo_peticao_id: payload.tipo_peticao_id, nivel_qualidade_ia: payload.qualidade, status: 'PENDENTE', meta: { origem: 'flow', flow_added_at: new Date().toISOString() }, }).select('id').single(); // 2. Chama EF olivia-topicos com historico_id criado await supabase.functions.invoke('olivia-topicos', { body: { historico_id: row.id, doc_urls: payload.doc_urls, ... }, }); // Realtime do drawer pega UPDATE status=PROCESSANDO automaticamente }

12. Riscos identificados

⚙️
Concorrência Mac Mini sem fila interna

Confirmado: analise.mjs em produção dispara setImmediate fire-and-forget. Se drawer dispara 8 EFs ao mesmo tempo, vão para o Mac Mini paralelas (risco 429 acima de 5). Mitigação D-15=B: useFlowQueue sequencia 5 por vez localmente.

🪟
Empilhamento Drawer→Modal→Drawer

shadcn defaults usam z-50 em todos. Resolvível com prop className="z-[60]" (modal) e className="z-[70]" (drawer restrições). Trivial — sem hack.

📱
Mobile (375px)

Drawer vira fullscreen. Modal vira fullscreen. Drawer Restrições sobre modal — fullscreen sobre fullscreen funciona mas usuário "perde" 2 níveis. Mitigação: breadcrumb topo do Drawer Restrições "← Voltar ao processo".

💾
Modal fecha = perde formulário

Se usuário clica fora ou ESC sem confirmar, perde tudo digitado. Mitigação: confirm dialog "Descartar processo? Você preencheu CNJ + 2 docs" se houver dirty state.

📡
10 channels Realtime simultâneos

1 channel por card. Supabase Pro aguenta 200. Mas se usuário abre 10 + tem 5 abas VibeLaw também ouvindo Realtime = 15 channels. Tranquilo. Apenas monitorar.
