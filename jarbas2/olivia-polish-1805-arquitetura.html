O Que Eu Faria Diferente — Proposta Arquitetural

💡
Filosofia central da proposta O problema não é o modelo de IA — o Sonnet 4.6 gera conteúdo jurídico de qualidade. O problema é de orquestração de contexto: a IA não recebe as informações certas na hora certa. A solução é arquitetural, não de prompt.
Arquitetura proposta em 3 camadas
CAMADA 1 — ANÁLISE ENRIQUECIDA
Atual (funciona bem) + 2 melhorias:
1. Pré-carregar conteúdo dos blocos escolhidos (não só bloco_id)
2. Pré-selecionar 1 juris por seção do mapa_secoes
↓ entrega: analise_estruturada + blocos_resolvidos + juris_por_secao
CAMADA 2 — GERAÇÃO POR SEÇÃO (APRIMORADA)
Para cada seção, prompt inclui:
• Título + argumento_unico + nao_repetir (atual)
• Bloco de referência da tag daquela seção (NOVO)
• Jurisprudência pré-selecionada para esta seção (NOVO)
• Instrução: "adapte ao caso, não copie o bloco"
↓ entrega: secoes_geradas com blocos_usados e juris corretas
CAMADA 3 — PÓS-PROCESSAMENTO INTELIGENTE
1. Anti-repetição: substituição lexical programática (não IA)
2. Garantir DOS PEDIDOS: template fixo por persona se não gerado
3. Ordenação: garantir preliminares antes do mérito
4. Dedup de fechamento: remover "pede deferimento" duplicado
5. Validator semântico: match por keywords, não slot exato
Anti-repetição: mover para pós-processamento programático

Em vez de pedir à IA para não repetir nomes (ela falha), fazer substituição programática no HTML final:

function antiRepeticaoLexica(html, dadosCaso) { const subs = [ [dadosCaso.empresa_re, [ 'a parte ré', 'o banco', 'a instituição', 'a demandada' ]], [dadosCaso.nome_autor, [ 'a parte autora', 'o(a) autor(a)', 'o consumidor' ]], ]; // Substituir ocorrências 3+ mantendo a 1ª e 2ª intactas return substituirComContador(html, subs, maxAparições=2); }

Custo: zero tokens adicionais. Determinístico. Sem variação de sessão para sessão.

DOS PEDIDOS: template fixo por persona

Se a análise não gerar tópico de pedidos, inserir template canônico programaticamente:

const TEMPLATE_PEDIDOS = { christian: `<h2>DOS PEDIDOS</h2> <p>Diante do exposto, REQUER:</p> <ol type="1" style="margin-left:3em"> <li>Concessão da AJG...</li> <li>Declaração de inexigibilidade do débito...</li> <li>Condenação em danos morais: R$ {{valor}}...</li> <li>Honorários sucumbenciais (CPC art. 85)...</li> </ol>`, heloisa: `<h2>Dos Pedidos Finais</h2>...` };

A IA completa com valores do caso; o template garante estrutura formal sempre presente.
