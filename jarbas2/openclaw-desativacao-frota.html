1. Objetivo

Desativar a OpenClaw (o agente conversacional via Telegram) dos agentes Mia, Cecilia, Jarbas, Beto e Olivia no Mac Mini, porque estão ociosos e o gateway faz polling + responde via LLM 24/7 — consumindo tokens. Não excluir nada: apenas parar e marcar como disabled no launchd, de forma que religar seja trivial (um comando / uma skill /openclaw:on).

2. O que é a OpenClaw aqui (e o que consome tokens)

Cada agente roda em um user separado do Mac Mini, com workspace em ~/.openclaw/workspace-<nome>/. Cada user tem dois tipos de processo:

  • Gateway (openclaw-gateway, Node) — escuta o Telegram e responde via LLM. É ISTO que consome tokens
  • Workers (EPROC/distribuição, pipeline S0-S9, chat-server) — Node puro, automação determinística. NÃO consome tokens de LLM

Decisão CTO: desligar apenas os gateways. Os workers permanecem intactos — distribuição da Mia e pipeline da Cecilia continuam disponíveis.

6. Método — desativar (reversível, persiste reboot)

Padrão launchd moderno: bootout (para agora) + disable (impede relançar no boot — grava no override DB, sobrevive a reboot). Os plists não são apagados → religar é trivial. Rodar via ssh mac-mini-tail (user jarbas, sudo NOPASSWD).

LaunchAgents per-user (cecilia, jarbas, olivia, beto)

# Cecilia
sudo launchctl bootout  gui/506/ai.openclaw.cecilia 2>/dev/null
sudo launchctl disable  gui/506/ai.openclaw.cecilia
# Jarbas
sudo launchctl bootout  gui/502/ai.openclaw.gateway 2>/dev/null
sudo launchctl disable  gui/502/ai.openclaw.gateway
# Olivia
sudo launchctl bootout  gui/503/ai.openclaw.gateway 2>/dev/null
sudo launchctl disable  gui/503/ai.openclaw.gateway
# Beto (já parado — consolidar)
sudo launchctl bootout  gui/504/ai.openclaw.gateway 2>/dev/null
sudo launchctl disable  gui/504/ai.openclaw.gateway

LaunchDaemon system (mia)

sudo launchctl bootout  system/ai.openclaw.mia.gateway 2>/dev/null
sudo launchctl disable  system/ai.openclaw.mia.gateway

Verificar (esperado: 0 processos gateway nos 5 users)

ps -axo user,pid,command | grep openclaw-gateway | grep -v grep

7. Reversão — religar (a qualquer momento)

enable + bootstrap reverte exatamente. Para o beto, restaurar o nome do arquivo.

# Cecilia / Jarbas / Olivia (gui)
sudo launchctl enable    gui/506/ai.openclaw.cecilia
sudo launchctl bootstrap gui/506 /Users/cecilia/Library/LaunchAgents/ai.openclaw.cecilia.plist
sudo launchctl enable    gui/502/ai.openclaw.gateway
sudo launchctl bootstrap gui/502 /Users/jarbas/Library/LaunchAgents/ai.openclaw.gateway.plist
sudo launchctl enable    gui/503/ai.openclaw.gateway
sudo launchctl bootstrap gui/503 /Users/olivia/Library/LaunchAgents/ai.openclaw.gateway.plist
# Beto (renomear de volta, se .disabled)
P=/Users/beto/Library/LaunchAgents/ai.openclaw.gateway.plist
[ -f "$P.disabled" ] && sudo mv "$P.disabled" "$P"
sudo launchctl enable    gui/504/ai.openclaw.gateway
sudo launchctl bootstrap gui/504 "$P"
# Mia (system)
sudo launchctl enable    system/ai.openclaw.mia.gateway
sudo launchctl bootstrap system /Library/LaunchDaemons/ai.openclaw.mia.gateway.plist
