INV-A
Step 2 mockup contamination
P0 frontend · ANDRESSA/BMG leak
▶

Root Cause

/Users/christianpaz/beta-mdflow/src/hooks/olivia/relatorio/mockAnaliseJsonV5.ts tem hardcoded ANDRESSA MACHADO + BANCO BMG + R$ 121,70. Quando analise_json é null (PROCESSANDO/erro), o frontend renderiza o mock. A flag ENABLE_MOCK_FALLBACK = import.meta.env.DEV deveria bloquear PROD, mas o mock vaza por path indireto via useAnaliseJsonStructured.

Evidência Runtime

Processo 5010472-39.2025.8.21.0001: analise_json: PROCESSANDO (null) HTML renderizado: 27× WILLIAM (autor real) + 5× ANDRESSA (do mock) Supabase olivia_historico.analise_json IS NULL Frontend cai em mock fallback

Fix Proposto

  • Sanitizar mockAnaliseJsonV5.ts com dados genéricos (JOÃO DA SILVA + BANCO DO BRASIL + R$ 100,00)
  • ENABLE_MOCK_FALLBACK = false em PROD (forçar via env VITE_MOCK_FALLBACK)
  • Guarda extra status !== 'PROCESSANDO' antes de chamar parser
  • Validator processo_id check no consolidator (peça com nome diferente do autor real → REJEITAR)

server.mjs não propaga usar_multi_agent ao pipelineInput (fix aplicado em commit a77b211 mas pode estar incompleto). Frontend NÃO envia a flag no payload. Env OLIVIA_MULTI_AGENT=true presente no LaunchDaemon mas validação interna do orchestrator falha silenciosa em buildWorkerSpecs.
