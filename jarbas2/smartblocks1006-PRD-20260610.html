Objetivo único desta rodada: fechar essas lacunas. Zero features novas (ideias I-01..I-10 rejeitadas pelo CTO), zero refactor (W4 adiada), zero mudança no VibeLaw.

CORREÇÃO 1 T06 estava parcialmente duplicado

"Voltar à revisão" já existe e funciona durante 'gerando' (GenerationOverlay.tsx:189-198, sem disabled; overlay fecha por early-return :134 com hooks vivos). O gap REAL: handleRetry (:128-132) não valida status — POST duplicado possível até durante 'gerando'. Spec/T06 reescopadas para o bug real (gate + re-marcar 'gerando').

CORREÇÃO 2 T03 ganhou nota arquitetural obrigatória

Com HTTP 200 success:false, o front só mostra toast (useOliviaGenerator.onSuccess switch action; webhook.ts:109 só lança em !response.ok) e não atualiza o banco. A sincronização do status='erro' vem EXCLUSIVAMENTE do marcar_erro do branch (Realtime → UI). useOliviaGenerator/webhook.ts são compartilhados com o VibeLaw → intocáveis. Caso extremo sem smart_block_id → watchdog cobre em ≤15min.

8 · DoD (spec §8) & guard-rails

Definition of Done — 7 itens
  1. curl envelope inválido → HTTP 200 success:false action:toast_error
  2. Watchdog mata sessão fake ('gerando' antiga → GENERATION_TIMEOUT)
  3. Geração real → GDoc + 'finalizada' + gas_stats preenchido
  4. VibeLaw íntegro: payload RPC ok + braço writeback inalterado (diff)
  5. Overlay: 1 POST por geração; retry só em erro
  6. tsc=0 · build ✓ · n8n_validate_workflow ✓
  7. /report + commit pt-BR + push origin main
