7. Como o usuário testa

  1. Recarregar https://preview-beta-mdflow.lovable.app/olivia (aguardar Lovable rebuild ~30s)
  2. Clicar "Nova petição" → "VibeLaw 2.0 Beta" (3º card)
  3. Step 1: processo + categoria + tipo + modelo + versão
  4. Section "Documentos para análise" — opcional, expanda e arraste PDFs (contestação, decisão, etc)
  5. (Opcional) instruções pra Olivia
  6. Clica "Próximo — Wizard"
  7. Step 2: overlay "Olivia 2.0 está analisando" com barra de progresso real-time crescendo (5% → 95%)
  8. Tools T-XX vão aparecendo como tags conforme chamadas
  9. Em ~8-10 min: editor preenchido + score
  10. Concluir → Step 3 (downloads DOCX/PDF/HTML + rubric)
Garantias UI: SSE + polling 5s + watchdog 35min em paralelo. Se SSE quebrar no browser → polling assume. Se backend silenciar → polling detecta. Se nada acontecer em 35min → erro visível com botão "Tentar novamente". Zero tela travada possível.
