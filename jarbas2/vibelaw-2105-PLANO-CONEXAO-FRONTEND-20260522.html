  1. Descobrir URL Cloudflare Tunnel (manual — login dashboard). Salvar em .env: VITE_OLIVIA_SERVER_URL=https://<...>.cfargotunnel.com
  2. Reescrever vibe-v2.service.ts:
    • const BASE_URL = import.meta.env.VITE_OLIVIA_SERVER_URL
    • DEFAULT_HEADERS: trocar mdflow por Authorization: \`Bearer ${TOKEN}\`
    • postJson: URL = ${BASE_URL}${path} (sem o /webhook)
    • createScoreEventSource: ${BASE_URL}/vibe/score?peticao_id=...
  3. Remover INSERT olivia_peticoes_v2 em vibelaw-v2/index.tsx handleStep1Next. Backend já persiste em olivia_historico.
  4. USE_MOCK default = false agora que backend existe.
  5. Smoke test via Lovable preview: avançar Step 1 → Step 2 → ver 202 → SSE conecta → score atualiza.

Fase 2 — Adaptar SSE events (30 min)

  1. Em useVibeV2Gerar.ts ajustar parser pra eventos reais do backend: 
    case 'score':  → onScore(rubric) + onChunk se houver progresso_msg
case 'done':   → onDone(peca_html, rubric)  [fetch /olivia_historico GET → peca_html]
case 'error':  → onError + closeSSE
  2. Como peca_html não vem no SSE, no evento done fazer supabase.from('olivia_historico').select('peticao_html, score_revisor').eq('id', peticao_id).single()

  4. Validar peça gerada em olivia_historico.peticao_html
  5. Comparar score com baseline V1 (esperado: V2 +6.94 pontos = ~8.5/10)
