O Problema e a Solucao

O Problema — Cecilia v1-v7
  • 100% intimacoes produzem movimento_em_duvida
  • Pipeline S0-S9 rigido e monolitico
  • Judit API: R$7.637/mes + TJRS retorna attachments vazios
  • 8.485 processos ativos MP Advocacia sem monitoramento util
  • CECILIA_IA_MODEL nunca setada — usava claude-sonnet-4-5 sem querer
  • 100% movimentos_em_duvida por modelo errado + contexto zerado
A Solucao — Cecilia v2
  • XLS-driven queue substituindo polling cego
  • SDK Agent com 3 camadas de contexto (threads + snapshot + Obsidian)
  • haiku-4.5 triagem binaria + regex 80% cobertura = economia maxima
  • Sonnet 4.6 hardcoded (jamais env var) — fix definitivo do bug v1
  • Worker A: Playwright sequencial 1 sessao EPROC por OAB
  • Worker B: 35 regras regex editaveis por Joao via frontend
  • Worker C: HTTP GET direto (sem Playwright) + fn_intimacao_insert_validated
  • Meta: <20% movimento_em_duvida vs 100% hoje
