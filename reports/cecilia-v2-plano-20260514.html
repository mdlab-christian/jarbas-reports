Custo Estimado vs. Judit API

Judit API (descartada)
R$7.637
por mes · TJRS sempre vazio · D9=descartada
Cecilia v2 (IA)
~$4-9
USD por mes · economiza +99%
Worker B (haiku-4.5 triagem) ~$0.40/mes
Worker C (Sonnet 4.6 analise) ~$3-8/mes
Total estimado ~$4-9 USD/mes
Por que haiku na triagem e a decisao critica (D6)

Worker B descarta 70-80% das movimentacoes como ruido. Com haiku-4.5, o custo por triagem cai 20x comparado ao Sonnet. Apenas movimentacoes classificadas como relevante sobem para o Worker C com Sonnet 4.6 e SDK Agent completo. Isso garante que o custo de IA escala sublinearmente com o volume de processos.
